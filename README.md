# Portfolio — Juan Daniel Ordoñez

Portafolio personal responsive construido con HTML, CSS y JavaScript. Presenta perfil profesional, stack técnico, proyectos, trayectoria y canales de contacto.

## Ejecutar localmente

No requiere instalación ni proceso de build. Abre `index.html` directamente o inicia un servidor local:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000`.
